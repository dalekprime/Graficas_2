Técnicas de Rasterización y Ray Tracing

1. Arquitectura del Motor

El proyecto es un motor híbrido que combina el pipeline tradicional de Rasterización con algoritmos de Ray Tracing por GPU. Todo se ha diseñado de manera altamente acoplada usando un grafo de escena jerárquico.

  • Scene Management: Abstracción usando nodos y parseo nativo de glTF mediante TinyGLTF.
  • Materiales: Abstracción física PBR (Cook-Torrance).
  • Shaders: Rasterización (Planar, Lambert, Blinn-Phong, PBR) y Compute/Fragment (RayTracing).

2. Carga y Serialización (glTF)

Estructura Jerárquica

El motor implementa un Grafo de Escena. La posición en el mundo de cualquier nodo se calcula propagando su matriz local hacia abajo:

$$ M_{mundo} = M_{padre} \times M_{local} $$ $$ M_{local} = T \times R \times S $$

Se utiliza TinyGLTF para parsear los arreglos binarios (buffers) decodificando las posiciones, normales, y UVs.


// Extracción de Datos Crudos en Scene::LoadFromGLTF
if (GetAttributeData("POSITION", dataPtr, stride, model, primitive)) {
    for (size_t i = 0; i < vertices.size(); i++) {
        const float* ptr = reinterpret_cast(dataPtr + i * stride);
        vertices[i].position = glm::vec3(ptr[0], ptr[1], ptr[2]);
    }
}

3. Sólidos de Revolución (Bézier)

Algoritmo de De Casteljau

Para construir el perfil de revolución, se evalúa una curva de Bézier mediante el algoritmo de De Casteljau, el cual interpola linealmente puntos de control iterativamente:

$$ P_i^{(k)} = (1 - t) P_i^{(k-1)} + t P_{i+1}^{(k-1)} $$

Una vez obtenido el perfil 2D, se extruye a 3D barriendo un ángulo de 0 a 360 grados ($2\pi$) alrededor de un eje (ej. Eje Y).


// Revolución en Eje Y (Solid.cpp)
for (int s = 0; s <= segments; s++) {
    float angle = s * angleStep;
    float cosA = glm::cos(angle);
    float sinA = glm::sin(angle);
    for (size_t p = 0; p < profile.size(); p++) {
        v.position = glm::vec3(profile[p].x * cosA, 
                               profile[p].y, 
                               profile[p].x * -sinA);
        vertices.push_back(v);
    }
}

4. Cálculo de Espacio Tangente

Para que el Normal Mapping (PBR) funcione, se requiere la base ortonormal TBN (Tangent, Bitangent, Normal). Esto se resuelve al calcular la derivada de las posiciones 3D respecto a las coordenadas UV.

$$ \Delta P_1 = \Delta U_1 \mathbf{T} + \Delta V_1 \mathbf{B} $$ $$ \Delta P_2 = \Delta U_2 \mathbf{T} + \Delta V_2 \mathbf{B} $$

Invirtiendo la matriz, resolvemos para la Tangente ($\mathbf{T}$) y la Bitangente ($\mathbf{B}$). Posteriormente, se promedia a nivel de vértice y se ortogonaliza usando Gram-Schmidt.


// Cálculo de Tangentes (Solid.cpp)
float r = 1.0f / (deltaUV1.x * deltaUV2.y - deltaUV1.y * deltaUV2.x);
glm::vec3 tangent = (deltaPos1 * deltaUV2.y - deltaPos2 * deltaUV1.y) * r;
glm::vec3 bitangent = (deltaPos2 * deltaUV1.x - deltaPos1 * deltaUV2.x) * r;

vertices[i0].tangent += tangent;
// Al final, se normaliza para promediar las caras adyacentes.

5. Interacción: Ray Casting (Mouse Picking)

Möller-Trumbore (Ray-Triangle)

El rayo se lanza calculando el inverso de la Matriz de Vista y Proyección. Para intersectar eficientemente, se usa AABB como fase ancha, y Möller-Trumbore para precisión exacta usando coordenadas baricéntricas $(u, v)$.

$$ \vec{O} + t\vec{D} = (1 - u - v)\vec{V_0} + u\vec{V_1} + v\vec{V_2} $$ $$ \begin{bmatrix} t \\ u \\ v \end{bmatrix} = \frac{1}{\vec{D} \times \vec{E_2} \cdot \vec{E_1}} \begin{bmatrix} \vec{S} \times \vec{E_1} \cdot \vec{E_2} \\ \vec{D} \times \vec{E_2} \cdot \vec{S} \\ \vec{S} \times \vec{E_1} \cdot \vec{D} \end{bmatrix} $$ 

// Fragment Shader (RTShader.frag) Möller-Trumbore
bool RayTriangleIntersect(Ray ray, vec3 v0, vec3 v1, vec3 v2, out float t, out vec2 uv) {
    vec3 edge1 = v1 - v0;
    vec3 edge2 = v2 - v0;
    vec3 h = cross(ray.direction, edge2);
    float a = dot(edge1, h);
    if (abs(a) < 1e-7) return false;
    float f = 1.0 / a;
    vec3 s = ray.origin - v0;
    float u = f * dot(s, h);
    if (u < 0.0 || u > 1.0) return false;
    vec3 q = cross(s, edge1);
    float v = f * dot(ray.direction, q);
    if (v < 0.0 || u + v > 1.0) return false;
    t = f * dot(edge2, q);
    uv = vec2(u, v);
    return t > 0.001;
}

6. Iluminación PBR (Physically Based Rendering)

BRDF Cook-Torrance y Ecuación de Renderizado

El motor implementa el modelo de microfacetas estándar de la industria. La luz entrante se divide en energía difusa ($k_d$) y especular ($k_s$). La componente especular se resuelve con:

$$ f_{r} = k_d \frac{c_{albedo}}{\pi} + \frac{D \cdot F \cdot G}{4 (\omega_o \cdot n)(\omega_i \cdot n)} $$
  • D (Distribución Normal GGX): Estima qué porcentaje de microfacetas están alineadas con el vector Halfway $H$. Define el tamaño y brillo del reflejo especular basándose en la Rugosidad ($\alpha$).
    $$ D(n, h, \alpha) = \frac{\alpha^2}{\pi ((n \cdot h)^2 (\alpha^2 - 1) + 1)^2} $$
  • F (Fresnel-Schlick): Describe la relación de luz reflejada vs refractada en ángulos rasantes. A mayor ángulo, las superficies se vuelven espejos perfectos.
    $$ F(v, h) = F_0 + (1 - F_0)(1 - (v \cdot h))^5 $$
  • G (Geometría Schlick-GGX): Modela el auto-sombreado de las microfacetas (cuando unas bloquean a otras). Usa el método de Smith para combinar la oclusión del observador y la luz.

// Distribución Normal (pbrShader.frag)
float D_GGX(vec3 N, vec3 H, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float denom = (NdotH*NdotH * (a2 - 1.0) + 1.0);
    denom = PI * denom * denom;
    return a2 / max(denom, 0.0000001);
}
// Factor de Fresnel (Aproximación de Schlick)
vec3 F_Schlick(vec3 H, vec3 V, vec3 albedo, float metalic) {
    float HdotV = max(dot(H, V), 0.0);
    vec3 F0 = mix(vec3(0.04), albedo, metalic); // F0 base
    return F0 + (1.0 - F0) * pow(1.0 - HdotV, 5.0);
}

7. Esquema Visual: PBR y Vectores

En el PBR, la luz incidente se divide para conservar la energía general. Nunca se refleja más luz de la que entra.

  • Lóbulo Difuso ($k_d$): La luz penetra ligeramente la superficie, rebotando internamente (dispersión) y volviendo a salir teñida uniformemente con el Albedo.
  • Lóbulo Especular ($k_s$): La luz rebota en la superficie de inmediato. El vector H (Halfway) es crucial para calcular matemáticamente cuántas microfacetas de la geometría apuntan exactamente hacia el observador.

8. Shadow Mapping Clásico y PCF

El Mapa de Profundidad

La escena se renderiza primero desde la perspectiva de la luz para guardar la profundidad en el Z-Buffer (`depthMapFBO`). En el segundo paso, se compara la profundidad del fragmento actual contra el mapa.

Limitaciones y Soluciones:

  • Shadow Acne: Se mitiga sumando un Bias pequeño a la comparación de profundidad.
  • Aliasing (Bordes Dentados): Se aplica PCF (Percentage Closer Filtering), haciendo muestreos promediados (Ej. kernel 3x3) en los texels vecinos.

// Percentage Closer Filtering (pbrShader.frag)
float shadowPCF = 0.0;
vec2 texel = 1.0 / textureSize(uShadowMap, 0);
for(int x = -pcfLimit; x <= pcfLimit; x++) {
    for(int y = -pcfLimit; y <= pcfLimit; y++) {
        float d = texture(uShadowMap, proj.xy + vec2(x, y) * texel).r;
        // Se aplica el Bias para evitar Shadow Acne
        shadowPCF += currentDepth - bias > d ? 1.0 : 0.0;
    }
}
return shadowPCF / float(pcfSize * pcfSize);

9. Sombras Suaves (PCSS)

Percentage Closer Soft Shadows

Simula el tamaño físico de la luz para lograr sombras nítidas de cerca y borrosas (penumbra) a lo lejos.

  1. Blocker Search: Se busca en un radio los objetos que ocluyen y se promedia su profundidad ($d_{blocker}$).
  2. Estimación de Penumbra:
    $$ w_{penumbra} = \frac{d_{receiver} - d_{blocker}}{d_{blocker}} \times w_{light} $$
  3. Filtrado: Se ejecuta un PCF dinámico donde el radio del filtro es igual al tamaño de la penumbra calculada.

// Estimación de Penumbra y Filtro (pbrShader.frag)
float distanceToBlocker = max(currentDepth - avgBlockerDepth, 0.0);
float penumbra = distanceToBlocker * pcssSize;
float filterRadius = clamp(penumbra, 1.0, 20.0);

int samples = 0;
for(int x = -2; x <= 2; x++) {
    for(int y = -2; y <= 2; y++) {
        float d = texture(uShadowMap, proj.xy + vec2(x,y) * texel * filterRadius).r;
        shadowPCSS += (currentDepth - bias > d) ? 1.0 : 0.0;
        samples++;
    }
}

10. Esquema: Anatomía de la Penumbra (PCSS)

A diferencia del Shadow Mapping clásico donde la luz se trata como un "punto" infinitamente pequeño, PCSS asume matemáticamente que la luz tiene un "Área" física (esfera o disco).

Esto produce sombras hiper-realistas que se van difuminando progresivamente entre más lejos esté el objeto que proyecta la sombra del objeto que la recibe.

11. Ray Tracing: Arquitectura y Stack Iterativo

Abstracción SSBO y Bucle Principal

El motor recolecta toda la geometría (vértices, índices) y atributos (materiales, normales, nodos del grafo) y los empaqueta en Shader Storage Buffer Objects (SSBOs), enviándolos al Fragment Shader (RTShader.frag).

Ya que GLSL no permite recursión pura para re-lanzar rayos desde una intersección, se implementó un Stack Finito simulado en un arreglo de tamaño fijo (MAX_STACK = 6).

  • Cada iteración evalúa la intersección (Möller-Trumbore) de todos los nodos.
  • Se acumula el color en el parámetro Throughput.
  • Dependiendo del material (Base, Espejo, Cristal), se hace Push de 1 o 2 rayos nuevos al Stack (ej. rayo reflejado y refractado).

// Bucle principal de Path Tracing Iterativo
struct StackItem {
    Ray ray;
    vec3 throughput;
    int depth;
};
StackItem stack[MAX_STACK];
int stackPtr = 0;
stack[stackPtr] = StackItem(primaryRay, vec3(1.0), 0);

while (stackPtr >= 0 && stackPtr < MAX_STACK) {
    StackItem current = stack[stackPtr];
    stackPtr--; // Pop del rayo actual
    
    // Si la profundidad supera uMaxBounces, descartamos
    if (current.depth >= uMaxBounces) continue;

    HitRecord hit = TraverseScene(current.ray);
    // Evaluamos intersección y el material...
}

13. Ray Tracing: Refracción y Dieléctricos

Simulación de Cristal y Fluidos

Para procesar cristales o líquidos (matType == 2), la luz debe penetrar la geometría o reflejarse sobre ella dependiendo del ángulo de visión y la densidad del medio.

  • Ley de Snell: Determina la desviación de la luz usando el Índice de Refracción (IOR) relativo: $\eta = \frac{n_1}{n_2}$. GLSL provee refract(D, N, eta) para este fin.
  • Reflexión Interna Total (TIR): Al salir de un medio denso (ej. cristal a aire), si el ángulo supera el ángulo crítico, el rayo se refleja al 100% y no cruza la superficie.
  • Aproximación de Schlick: Calcula $R$, la probabilidad/cantidad de luz reflejada vs. refractada ($1-R$). Se apilan ambos rayos modulados por este ratio.

// Dieléctricos (Cristal)
float eta = hit.frontFace ? (1.0 / ior) : ior;
vec3 refrDir = refract(current.ray.direction, hit.normal, eta);

float R; // Coeficiente de Fresnel (Schlick)
float sinT2 = eta * eta * (1.0 - cosTheta * cosTheta);
if (sinT2 > 1.0 || length(refrDir) == 0.0) {
    R = 1.0; // TIR: Reflexión Interna Total
} else {
    float r0 = pow((1.0 - ior) / (1.0 + ior), 2.0);
    R = r0 + (1.0 - r0) * pow(1.0 - cosTheta, 5.0);
}

// Push Rayo Refractado (penetra)
if (R < 1.0) {
    stackPtr++;
    stack[stackPtr] = StackItem(Ray(hit.point - EPSILON, refrDir), 
                                current.throughput * (1.0 - R), current.depth + 1);
}
// Push Rayo Reflejado (rebota exterior)
if (R > 0.0) {
    stackPtr++;
    stack[stackPtr] = StackItem(Ray(hit.point + EPSILON, refDir), 
                                current.throughput * R, current.depth + 1);
}

14. Ray Tracing: Metales y Espejos

Reflexión Especular

Los metales puros y espejos tienen un comportamiento de absorción y rebote totalmente distinto a los no-metales (dieléctricos).

  • Espejo Perfecto (matType == 1): Toda la luz incidente rebota siguiendo la ley de reflexión: $R = D - 2(N \cdot D)N$. El vector se computa fácilmente con reflect() y se lanza un nuevo rayo al Stack sin pérdida de Throughput más que el albedo.
  • Metales Rugosos (matType == 0 y metallic > 0): Interpola la reflectancia usando el PBR local, modulando por un $F_0$ coloreado por el Albedo Base. La dispersión disminuye la energía refleja basándose en la Rugosidad.

// Espejo Perfecto (matType == 1)
vec3 refDir = reflect(current.ray.direction, hit.normal);
Ray refRay = Ray(hit.point + hit.geomNormal * EPSILON, refDir);

stackPtr++; // Agregamos al stack el nuevo rebote
stack[stackPtr] = StackItem(refRay, current.throughput * baseAlbedo, current.depth + 1);

// Metales PBR (matType == 0, metallic > 0.01)
// ... se calcula la luz local ...
vec3 F0 = mix(vec3(0.04), baseAlbedo, metallic);
vec3 F = F0 + (max(vec3(1.0 - roughness), F0) - F0) * pow(1.0 - cosTheta, 5.0);
float reflectionEnergy = 1.0 - roughness; // A menor rugosidad, más nítido el rayo

if (reflectionEnergy > 0.05) {
    vec3 refDir = reflect(current.ray.direction, hit.normal);
    stackPtr++;
    stack[stackPtr] = StackItem(Ray(hit.point + EPSILON, refDir), 
                                current.throughput * F * reflectionEnergy, current.depth + 1);
}

15. Rendimiento y Conclusiones

Observaciones Técnicas

  • Rendimiento: La rasterización estándar corre sumamente rápida. Sin embargo, el módulo de Ray Tracing decae exponencialmente de acuerdo a la complejidad poligonal de la escena debido a la carencia de estructuras de aceleración eficientes reales como BVH Jerárquicos en el Shader (solo se chequean AABBs lineales simples por nodo).
  • Extensibilidad: Gracias al robusto parseador glTF abstraído sobre TinyGLTF, el motor está preparado para soportar virtualmente cualquier malla exportada desde Blender.
  • Limitación Estructural: Por cómo se diseñaron los SSBOs, la limitación máxima de texturas indexables nativamente suele rondar los 16-32 arrays paralelos debido a la arquitectura de OpenGL 4.6 Core.
